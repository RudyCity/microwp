# microWP Community Code of Conduct

We want microWP to be welcoming to contributors with different backgrounds and levels of expertise. Discussions and reviews should stay professional, constructive, and respectful.

We expect contributors to:

- Discuss code and technical decisions rather than attacking people.
- Respect differences in experience, culture, and opinion.
- Give useful feedback, admit mistakes, and credit others' work.
- Avoid harassment, threats, discrimination, intimidation, or disclosure of private information.
- Follow responsible security disclosure practices.

Maintainers may moderate issues, discussions, and pull requests, including hiding or closing content that violates these expectations. If you need to report a conduct concern, contact a repository maintainer privately rather than posting personal details in an issue.
